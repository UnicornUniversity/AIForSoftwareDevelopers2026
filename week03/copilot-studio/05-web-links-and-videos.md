# External Web and Video Sources

The four Markdown files (01–04) give NotebookLM a coherent internal corpus. To demonstrate NotebookLM's ability to ingest **web pages and YouTube videos**, add the following as separate sources during the demo. In NotebookLM click **Add source → Website** for URLs and **Add source → YouTube** for videos.

## Web pages (URLs)

Paste each of these one at a time as a **Website** source.

- **Coffee — Wikipedia (general overview):**
  https://en.wikipedia.org/wiki/Coffee

- **Coffee bean — Wikipedia (focus on the seed/bean):**
  https://en.wikipedia.org/wiki/Coffee_bean

- **Coffee production — Wikipedia (global production, top producers):**
  https://en.wikipedia.org/wiki/Coffee_production

- **Coffee roasting — Wikipedia (roast levels, chemistry):**
  https://en.wikipedia.org/wiki/Coffee_roasting

- **Specialty Coffee Association — official homepage:**
  https://sca.coffee/
